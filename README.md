# The Sheepdog Collective Website

A Next.js + Tailwind starter site for The Sheepdog Collective.

## Install

Copy these files into:

`C:\ByteBiz\thesheepdogcollective.com`

Then run:

```powershell
npm install
npm run dev
```

Open:

`http://localhost:3000`

## Included

- Homepage
- Programs page
- Individual course detail pages
- Calendar placeholder
- About page
- Affiliates page
- Contact page
- Logo and Shotgun Breaching flyer assets
- CMS-ready content structure in `lib/site-data.ts`
